# Divyabharathi V — Developer Command Center

A responsive, resume-grounded static portfolio built with HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension for live reload. The portfolio does not require a server-side backend.

## Update portfolio content

Edit `js/data.js`. It is the single source for the profile, education, skills, projects, certifications, and journey data used by the page.

## Resume file

The original resume PDF was not available when this site was created. To enable the resume actions, add the original PDF under `assets/resume/` and update the resume links in `index.html` and `js/script.js`. Do not replace it with an invented resume.

## Factual-content note

Portfolio descriptions and profile details are limited to the information supplied in the provided brief. No photo, certificate issuer/date, project deployment, GitHub statistics, or unsupported project details have been added.
